# LifeFlow (زندگی‌آرام) — Obsidian Plugin

مدیریت تسک، برنامه‌ریزی روزانه، مطالعه، یادگیری و پومودورو داخل Obsidian.

برای وضعیت فعلی توسعه و نقشه‌راه، فایل `PROGRESS.md` را ببینید — این فایل مرجع اصلی است و باید قبل از هر جلسه‌ی کاری (چه توسط Claude، چه هر ابزار دیگر) خوانده شود و بعد از هر تغییر به‌روزرسانی گردد.
